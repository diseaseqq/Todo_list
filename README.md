# Список задач

Небольшое браузерное приложение для планирования задач. Работает на чистом HTML, CSS и JavaScript без сборщика и внешних зависимостей.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сервер разработки не требуются.

## Возможности

- Создание и редактирование задач с описанием, сроком, приоритетом и категорией.
- Подзадачи и повторение задач.
- Поиск по названию и описанию, фильтрация и сортировка.
- Статистика активных, выполненных и просроченных задач.
- Архив с восстановлением и окончательным удалением.
- Светлая и тёмная темы.

Задачи и настройки сохраняются в `localStorage` текущего браузера. Они не синхронизируются между браузерами или устройствами.

## Backend (в разработке)

Backend использует PHP 8.3 и PDO_SQLite без внешнего фреймворка. Добавлены версионированные миграции, CLI-команды обслуживания базы, создание первого администратора и начальные API-маршруты аккаунта. API задач и переключение интерфейса ещё не реализованы.

Для локального запуска нужны PHP CLI 8.3 и расширения PDO_SQLite и mbstring. PHP должен запускаться из корня проекта с `public/index.php` как router script. В окружении разработки задайте `TODO_ENV=development`; путь БД по умолчанию — `storage/app.sqlite`. Production обязан явно передать абсолютный `TODO_DB_PATH` вне каталога `public`, иначе конфигурация завершается ошибкой. Файл `.env.example` служит памяткой переменных окружения и автоматически не загружается.

Пошаговые инструкции по созданию первого аккаунта на Windows и на VPS приведены в [инструкции первого администратора](FIRST_ADMIN_SETUP.md). Команда интерактивно запросит email и пароль; стандартного пароля нет. Она создаёт также шесть стандартных категорий для этого аккаунта. Повторный запуск миграций безопасен, а повторное создание администратора отклоняется.

Начальные маршруты аккаунта: `GET /api/auth/csrf`, `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout` и `GET /api/auth/me`. Для POST-запросов сначала получите CSRF-токен и отправьте его в заголовке `X-CSRF-Token` вместе с JSON-телом запроса.

На целевом сервере используется PHP-FPM за Nginx. Каталог БД и резервные копии должны находиться вне публичного web-root; реальные пути и права описаны в [плане backend](BACKEND_SQLITE_IMPLEMENTATION_PLAN.md).
