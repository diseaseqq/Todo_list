# Список задач

Небольшое браузерное приложение для планирования задач. Работает на чистом HTML, CSS и JavaScript без сборщика и внешних зависимостей.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сервер разработки не требуются.

## Возможности

- Создание и редактирование задач с описанием, сроком, приоритетом и категорией.
- Подзадачи и повторение задач.
- Поиск по названию и описанию, фильтрация и сортировка.
- Статистика активных, выполненных и просроченных задач.
- Архив с восстановлением и окончательным удалением.
- Светлая и тёмная темы.

Задачи и настройки сохраняются в `localStorage` текущего браузера. Они не синхронизируются между браузерами или устройствами.
